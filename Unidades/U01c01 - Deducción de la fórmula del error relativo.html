#T01.01.- Deducción de la Fórmula del Error Relativo

📋 Enunciado

Partiendo de la definición de error absoluto como la diferencia entre el valor medido (o aproximado) y el valor real (o de referencia) de una magnitud, demostrar que el error relativo se expresa como el cociente entre el error absoluto y el valor real, multiplicado por 100 para expresarlo en porcentaje.

\[ \varepsilon_{a} = |v_{\text{aprox}} - v_{\text{real}}| \quad \Longrightarrow \quad \varepsilon_{r} = \frac{\varepsilon_{a}}{v_{\text{real}}} \times 100\,\% \]

🎯 Objetivo

Obtener una expresión que permita comparar la calidad de medidas de magnitudes muy diferentes. El error absoluto no basta para valorar la bondad de una medida: un error de \( 1\,\text{cm} \) al medir una mesa es grave, pero el mismo error al medir la distancia Tierra–Sol es despreciable. El error relativo proporciona una medida adimensional y normalizada del error, independiente de la escala de la magnitud medida.

🔬 Procedimiento

1 Definición del error absoluto

Se define el error absoluto \( \varepsilon_{a} \) como la diferencia entre el valor aproximado (medido) y el valor real (exacto) de una magnitud:

\[ \varepsilon_{a} = v_{\text{aprox}} - v_{\text{real}} \]

En valor absoluto, para que el error sea siempre positivo:

\[ \varepsilon_{a} = |v_{\text{aprox}} - v_{\text{real}}| \]
2 Limitación del error absoluto

El error absoluto tiene las mismas unidades que la magnitud medida. Por tanto, no permite comparar directamente la calidad de dos medidas de magnitudes distintas. Se necesita una magnitud adimensional que indique qué fracción del valor real representa el error.

3 Definición del error relativo

Se define el error relativo \( \varepsilon_{r} \) como el cociente entre el error absoluto y el valor real de la magnitud. De esta forma se eliminan las unidades y se obtiene una magnitud adimensional:

\[ \varepsilon_{r} = \frac{\varepsilon_{a}}{v_{\text{real}}} \]
4 Sustitución del error absoluto

Sustituyendo la definición de error absoluto en la expresión anterior:

\[ \varepsilon_{r} = \frac{v_{\text{aprox}} - v_{\text{real}}}{v_{\text{real}}} \]
5 Expresión en porcentaje

Para expresar el error relativo en forma de porcentaje, se multiplica por 100. Esto facilita su interpretación inmediata:

\[ \varepsilon_{r} (\%) = \frac{\varepsilon_{a}}{v_{\text{real}}} \times 100\,\% \]
6 Verificación dimensional

Verificación dimensional: las unidades de \( \varepsilon_{a} \) y \( v_{\text{real}} \) son idénticas, por lo que en el cociente se cancelan. El error relativo es, efectivamente, una magnitud adimensional:

\[ [\varepsilon_{r}] = \frac{[\varepsilon_{a}]}{[v_{\text{real}}]} = \frac{\text{unidad de la magnitud}}{\text{unidad de la magnitud}} = 1 \quad \text{(adimensional)} \]

✅ Resultado

La fórmula del error relativo, expresado en porcentaje, queda demostrada como:

\[ \boxed{\varepsilon_{r} = \frac{|v_{\text{aprox}} - v_{\text{real}}|}{v_{\text{real}}} \times 100\,\%} \]
💡 Observaciones sobre el alumnado:
Es importante destacar que el error relativo permite comparar la calidad de medidas de magnitudes distintas. Por ejemplo, un error de \( 2\,\text{cm} \) al medir una mesa de \( 100\,\text{cm} \) supone un \( \varepsilon_{r} = 2\,\% \), mientras que el mismo error de \( 2\,\text{cm} \) al medir un viaducto de \( 236\,\text{m} \) supone solo un \( \varepsilon_{r} \approx 0{,}008\,\% \).
🖱️ Pulsame — 🧪 DESMITIFICANDO EL ERROR RELATIVO
Ejercicio 1 Comparación de errores en medidas de longitud

Enunciado: Se mide la longitud de un lápiz y se obtiene \( 18{,}2\,\text{cm} \), siendo su valor real \( 18{,}0\,\text{cm} \). Paralelamente, se mide la altura de un edificio y se obtiene \( 45{,}8\,\text{m} \), siendo su valor real \( 46{,}0\,\text{m} \).

  • Calcula el error absoluto y el error relativo (en %) para cada medida.
  • ¿Cuál de las dos medidas es de mejor calidad (tiene menor error relativo)?

Resolución paso a paso:

Paso 1 – Error absoluto del lápiz: \[ \varepsilon_{a,\text{lápiz}} = |18{,}2 - 18{,}0| = 0{,}2\,\text{cm} \]
Paso 2 – Error relativo del lápiz: \[ \varepsilon_{r,\text{lápiz}} = \frac{0{,}2}{18{,}0} \times 100 = 1{,}11\,\% \]
Paso 3 – Error absoluto del edificio: \[ \varepsilon_{a,\text{edificio}} = |45{,}8 - 46{,}0| = 0{,}2\,\text{m} \]
Paso 4 – Error relativo del edificio: \[ \varepsilon_{r,\text{edificio}} = \frac{0{,}2}{46{,}0} \times 100 = 0{,}435\,\% \]
Conclusión: Aunque el error absoluto es el mismo (\(0{,}2\) unidades), el error relativo del edificio (\(0{,}435\%\)) es menor que el del lápiz (\(1{,}11\%\)). Por tanto, la medida del edificio tiene más calidad.
Ejercicio 2 Cálculo de error relativo en una pesada

Enunciado: Una balanza digital da una lectura de \( 245{,}3\,\text{g} \) para una muestra que realmente pesa \( 250{,}0\,\text{g} \).

  • Determina el error absoluto y el error relativo (en %) de esta medición.
  • Si el fabricante afirma que la balanza tiene un error máximo del \( 0{,}5\% \), ¿es aceptable esta medida?

Resolución paso a paso:

Paso 1 – Error absoluto: \[ \varepsilon_{a} = |245{,}3 - 250{,}0| = 4{,}7\,\text{g} \]
Paso 2 – Error relativo: \[ \varepsilon_{r} = \frac{4{,}7}{250{,}0} \times 100 = 1{,}88\,\% \]
Paso 3 – Comparación con el límite del fabricante: El error obtenido (\(1{,}88\%\)) es mayor que el máximo permitido (\(0{,}5\%\)). Por tanto, la medida no es aceptable según las especificaciones.
Ejercicio 3 Determinación del error absoluto a partir del error relativo

Enunciado: En un experimento de laboratorio se requiere que el error relativo en la medida de una resistencia eléctrica no supere el \( 2\% \). El valor real de la resistencia es \( 150\,\Omega \).

  • ¿Cuál es el error absoluto máximo admisible?
  • Si el voltímetro da una lectura de \( 153\,\Omega \), ¿cumple con la condición?

Resolución paso a paso:

Paso 1 – Despejar el error absoluto máximo: \[ \varepsilon_{r,\max} = 2\% = 0{,}02 \quad \Rightarrow \quad \varepsilon_{a,\max} = \varepsilon_{r,\max} \times v_{\text{real}} = 0{,}02 \times 150 = 3\,\Omega \]
Paso 2 – Calcular el error de la lectura: \[ \varepsilon_{a} = |153 - 150| = 3\,\Omega \]
Paso 3 – Comparar: El error absoluto es exactamente \( 3\,\Omega \), que es el máximo permitido. Por tanto, la medida cumple con la condición (está en el límite).
Ejercicio 4 Comparación de instrumentos (termómetros)

Enunciado: Dos termómetros miden la temperatura de un baño que realmente está a \( 37{,}0\,^\circ\text{C} \).

  • Termómetro A: indica \( 36{,}7\,^\circ\text{C} \).
  • Termómetro B: indica \( 37{,}5\,^\circ\text{C} \).
  • Calcula el error relativo de cada uno y determina cuál es más preciso (menor error relativo).

Resolución paso a paso:

Termómetro A: \[ \varepsilon_{a,A} = |36{,}7 - 37{,}0| = 0{,}3\,^\circ\text{C} \quad \Rightarrow \quad \varepsilon_{r,A} = \frac{0{,}3}{37{,}0} \times 100 = 0{,}81\% \]
Termómetro B: \[ \varepsilon_{a,B} = |37{,}5 - 37{,}0| = 0{,}5\,^\circ\text{C} \quad \Rightarrow \quad \varepsilon_{r,B} = \frac{0{,}5}{37{,}0} \times 100 = 1{,}35\% \]
Conclusión: El termómetro A tiene un error relativo (\(0{,}81\%\)) menor que el B (\(1{,}35\%\)), por lo que es más preciso (da una medida de mejor calidad).
Ejercicio 5 Aplicación en una constante física (aceleración de la gravedad)

Enunciado: En un laboratorio se mide la aceleración de la gravedad y se obtiene \( g = 9{,}78\,\text{m/s}^2 \). El valor aceptado es \( g = 9{,}81\,\text{m/s}^2 \).

  • Calcula el error relativo (en %) de esta medición.
  • Si otro grupo obtiene \( 9{,}92\,\text{m/s}^2 \), ¿cuál de los dos grupos ha realizado una medida de mejor calidad?

Resolución paso a paso:

Grupo 1: \[ \varepsilon_{a,1} = |9{,}78 - 9{,}81| = 0{,}03 \quad \Rightarrow \quad \varepsilon_{r,1} = \frac{0{,}03}{9{,}81} \times 100 = 0{,}306\% \]
Grupo 2: \[ \varepsilon_{a,2} = |9{,}92 - 9{,}81| = 0{,}11 \quad \Rightarrow \quad \varepsilon_{r,2} = \frac{0{,}11}{9{,}81} \times 100 = 1{,}12\% \]
Conclusión: El grupo 1 tiene un error relativo mucho menor (\(0{,}306\%\)) que el grupo 2 (\(1{,}12\%\)). Por tanto, la medida del grupo 1 es de mejor calidad.
Observaciones claves: El error relativo “normaliza” el error absoluto dividiéndolo por el valor real. Esto permite comparar medidas de órdenes de magnitud muy distintos (por ejemplo, micrómetros frente a kilómetros). La “trampa” mental que resuelve es que un error absoluto grande no siempre es malo si la magnitud medida es también grande; lo importante es la proporción que representa.

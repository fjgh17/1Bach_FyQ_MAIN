#T02.01.- Relación entre número másico, número atómico y neutrones

📋 Enunciado

Partiendo de las definiciones de número atómico \(Z\) (número de protones), número másico \(A\) (suma de protones y neutrones) y número de neutrones \(N\), demostrar que:

\[ A = Z + N \]

🎯 Objetivo

Obtener una fórmula general que permita calcular cualquiera de las tres magnitudes (másica, atómica o neutrones) conociendo las otras dos. Esta relación es la base para interpretar la notación isotópica y resolver problemas de composición nuclear sin necesidad de memorizar tablas.

🔧 Procedimiento

1 Definir el número atómico \(Z\): representa el número de protones presentes en el núcleo del átomo. Es una propiedad característica de cada elemento.
2 Definir el número másico \(A\): representa la suma del número de protones y el número de neutrones que contiene el núcleo.
\[ A = (\text{número de protones}) + (\text{número de neutrones}) \]
3 Identificar el número de neutrones \(N\): por definición, es la diferencia entre la masa nuclear total (másico) y la carga nuclear (atómico).
\[ N = A - Z \]
4 Comprobación algebraica: sustituyendo la expresión de \(N\) en la definición de \(A\):
\[ A = Z + (A - Z) = A \]
La identidad se verifica, confirmando la consistencia de la relación.

✅ Resultado

\[ A = Z + N \quad \Longleftrightarrow \quad N = A - Z \]
Observaciones sobre el alumnado: Es útil insistir en que \(Z\) es invariable para un elemento dado, mientras que \(A\) puede variar entre isótopos. Esta fórmula permite a los estudiantes deducir \(N\) directamente de la notación \(^A_Z\text{X}\) sin recurrir a datos externos.
🧪 DESMITIFICANDO Relación entre número másico, número atómico y neutrones Púlsame
1 Cálculo de neutrones a partir de \(A\) y \(Z\)

Un átomo neutro de un elemento tiene número másico \(A = 65\) y número atómico \(Z = 30\).

  • a) ¿Cuántos neutrones contiene su núcleo?
  • b) ¿Cuántos protones y electrones posee?

Resolución:

a) Usamos \(N = A - Z = 65 - 30 = 35\) neutrones.

b) Protones = \(Z = 30\). Al ser un átomo neutro, electrones = protones = 30.

El elemento es el zinc (\(^{65}_{30}\text{Zn}\)).

2 Ion con carga positiva

Un ion \(^{54}_{24}\text{Cr}^{3+}\)

  • a) Calcula el número de protones, neutrones y electrones que posee.
  • b) ¿Cuál es su número másico y su número atómico?

a) Protones = \(Z = 24\). Neutrones = \(A - Z = 54 - 24 = 30\).

Carga +3 indica que ha perdido 3 electrones: electrones = \(24 - 3 = 21\).

b) Número másico \(A = 54\), número atómico \(Z = 24\).

3 Ion con carga negativa

Un ion \(^{35}_{17}\text{Cl}^{-}\)

  • a) ¿Cuántos protones, neutrones y electrones tiene?
  • b) ¿Cuál es su número másico y su número atómico?

a) Protones = \(Z = 17\). Neutrones = \(35 - 17 = 18\).

Carga -1 indica que ha ganado 1 electrón: electrones = \(17 + 1 = 18\).

b) \(A = 35\), \(Z = 17\).

4 Cálculo de \(Z\) y \(A\) a partir de neutrones y electrones

Un ion dipositivo (\(2+\)) contiene 28 neutrones y 24 electrones. Determina:

  • a) El número atómico \(Z\) y el número másico \(A\).
  • b) El símbolo del ion (incluyendo número másico y carga).

a) Carga +2: protones = electrones + 2 = \(24 + 2 = 26\). Por tanto \(Z = 26\).

Neutrones = 28, luego \(A = Z + N = 26 + 28 = 54\).

b) El ion es \(^{54}_{26}\text{Fe}^{2+}\) (hierro-54, catión dipositivo).

5 Isótopos y abundancia

El galio natural está formado por dos isótopos: \(^{69}\text{Ga}\) (masa 68,93 u) y \(^{71}\text{Ga}\) (masa 70,92 u). La masa atómica promedio del galio es 69,72 u.

  • a) Calcula la abundancia porcentual de cada isótopo.
  • b) ¿Cuántos neutrones tiene cada isótopo? (Z del Ga = 31).

a) Sea \(x\) la fracción del isótopo \(^{69}\text{Ga}\). Entonces la fracción de \(^{71}\text{Ga}\) es \(1-x\).

\[ 68,93 \cdot x + 70,92 \cdot (1-x) = 69,72 \] \[ 68,93x + 70,92 - 70,92x = 69,72 \quad\Rightarrow\quad -1,99x = -1,20 \quad\Rightarrow\quad x = 0,603 \]

Por tanto, \(^{69}\text{Ga}\) tiene un 60,3 % y \(^{71}\text{Ga}\) un 39,7 %.

b) Neutrones: para \(^{69}\text{Ga}\): \(69 - 31 = 38\); para \(^{71}\text{Ga}\): \(71 - 31 = 40\).

💡 Observaciones claves: La relación \(A = Z + N\) es la base para interpretar la notación isotópica. Recuerda que \(Z\) es fijo para un elemento, pero \(A\) varía. Para iones, el número de electrones se ajusta restando o sumando la carga (en valor absoluto) a \(Z\).
